# Estadística Multivariada (Universidad La Salle)

Trabajos y ejercicios del curso de Estadística Multivariada, en Python.
Algunos notebooks parten de material y código base del profesor; las
versiones aquí incluyen mi documentación y mis modificaciones.

- LDA (análisis discriminante lineal) con datos simulados
- PCA: implementación y aplicación a la base Iris
- Optimización de portafolios de Markowitz (Monte Carlo)
- Clustering (k-means) y análisis de correspondencias

## Herramientas
Python, NumPy, pandas, scikit-learn, matplotlib
